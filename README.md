# Steel Jobwork ERP — Landing Page

This package recreates the supplied Steel ERP landing-page concept as a responsive HTML/CSS/JavaScript frontend.

## Included
- Left navigation
- Global search
- User profile
- Dynamic greeting/date/time
- Hero section
- Module grid
- My Approvals / My Tasks / Messages counters
- My Notes card
- Responsive desktop/tablet/mobile layouts

## Run
Open `index.html` in a browser.

## Next integration
Connect navigation and module buttons to the ERP routes, authentication/permissions, notifications, tasks, notes, and backend data.
